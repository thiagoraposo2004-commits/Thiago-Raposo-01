# Thiago Raposo — portfólio

Landing page estática em HTML, CSS e JavaScript puro, com narrativa de scrollytelling em base preta/branca e laranja usado apenas como destaque.

## Publicar gratuitamente

A opção mais simples é usar **GitHub Pages**: crie um repositório público, envie `index.html`, `styles.css`, `script.js`, `logo.svg`, `portrait.png`, `espm-logo.png` e `manus-routes.json`, abra **Settings → Pages**, selecione a branch `main` e a pasta raiz, e salve.

Também é compatível com Netlify, Vercel e Cloudflare Pages sem configuração adicional: basta apontar para a pasta do projeto. Se usar o build do projeto, `npm run build` gera a pasta `dist/` com os arquivos finais.

## Conteúdo

A página inclui a hero com a ilustração enviada pelo usuário, a seção **Sobre mim**, o curso **Liderança para Designers: do pixel perfeito à gestão de times — ESPM**, graduação em Publicidade e Propaganda pela UNIP, formação em Design Gráfico pela EBAC e Motion Design pela Escola do After.

O marcador **XY%** foi deixado como campo editável para receber um indicador real e validado. Os links de LinkedIn, Behance e Google Drive já estão conectados aos endereços fornecidos.

O arquivo `espm-logo.png` usado na seção de formação é a versão enviada pelo usuário na pasta mais recente do Google Drive.
